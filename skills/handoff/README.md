# handoff

- Maintainer: the productivity plugin maintainers
- Submitted: 2026-10-02

Compacts the current conversation into a handoff document a fresh agent can
continue from, saved to the OS temp folder rather than the workspace. It points
at existing artifacts instead of copying them, suggests skills for the next
agent, redacts secrets and personal data, and tailors the document to what the
user says the next session is for.

## Prerequisites

None beyond the agent.
