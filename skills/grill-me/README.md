# grill-me

- Maintainer: the productivity plugin maintainers
- Submitted: 2026-10-02

Interviews the user relentlessly about a plan or design, one question at a
time and each with a recommended answer, walking every branch of the decision
tree until both sides understand the plan the same way. Questions the codebase
can answer are answered by exploring it instead of asking.

## Prerequisites

None beyond the agent.
