# deepen

- Maintainer: the productivity plugin maintainers
- Submitted: 2026-10-18

Rewrites a task or prompt into a deeper version of itself, not a bigger one.
Before any work is done it names what a top professional would do that was not
asked for, the rawest material they would start from, the specific methods and
tools they would use, and what outside the agent and the user would show the
result is right. It then rewrites the request to ask for exactly that and waits
for the user to run it, edit it, or keep the original.

## Prerequisites

None beyond the agent.
