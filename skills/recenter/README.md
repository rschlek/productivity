# recenter

- Maintainer: the productivity plugin maintainers
- Submitted: 2026-11-07

Untangle for the whole session. It runs untangle's procedure with four
substitutions: the input is the chat from its first message, the unit is a
thread rather than a decision, each open thread gets a recommended destination
(finish here, drop, park, new chat, memory) instead of a choice, and the close
is a verdict, continue with a short agenda or close and seal the session. The
same procedure serves "where were we" after a device switch and "how do I
close this out" at the end.

## Prerequisites

None beyond the agent. A connected task tracker and a long-term memory tool
are used when present and described in plain words when not.
