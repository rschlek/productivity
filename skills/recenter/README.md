# recenter

- Maintainer: the productivity plugin maintainers
- Submitted: 2026-11-07

Reorients a chat around what it was opened to do. It restates the original
purpose from the first message, lists the threads the chat took on and marks
which drifted, ledgers each as done, in progress, or waiting on the user, gives
every open thread one destination (finish here, drop, park, new chat, memory),
and ends with a verdict: continue with a short agenda, or close and seal the
session. The same procedure serves "where were we" after a device switch and
"how do I close this out" at the end.

## Prerequisites

None beyond the agent. A connected task tracker and a long-term memory tool
are used when present and described in plain words when not.
