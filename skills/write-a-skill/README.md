# write-a-skill

- Maintainer: the productivity plugin maintainers
- Submitted: 2026-10-02

Authors a new agent skill, a `SKILL.md` plus optional bundled files, to a
short set of conventions: generic voice, portable, concise, and a description
that carries the trigger phrases and the nearest neighbors to avoid. It drafts
from the target repository's template when there is one and reviews the draft
with the user against a checklist.

## Prerequisites

None beyond the agent.
