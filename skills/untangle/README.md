# untangle

- Maintainer: the productivity plugin maintainers
- Submitted: 2026-10-02

Turns the agent's own pile of findings, options, jargon, or status into a short
sequence of small plain-language decisions. It gives the whole picture first,
sorts the pile into already decided, open, and not a decision, then walks the
open ones one per turn, each with a recommendation, and closes with a ledger
and a single question asking for the go.

## Prerequisites

None beyond the agent.
