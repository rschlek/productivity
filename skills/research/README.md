Spins up a background agent with a fresh context that investigates a question against primary sources (official docs, source code, specs, first-party APIs), writes the findings to one markdown file with each claim cited, and saves it where the project keeps such notes. One sentence was added to the original: when the work has no repository, the findings go where the project keeps its notes instead, such as a connected long-term memory tool.

## Prerequisites

A background agent facility in the harness. Otherwise nothing beyond the agent.
