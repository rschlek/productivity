# explain

- Maintainer: the productivity plugin maintainers
- Submitted: 2026-10-02

Explains one thing in plain language with no decisions attached: a problem, a
mechanism, a topic, or a piece of the agent's own output. It changes register
out loud, pins the subject with its evidence, gives the whole picture in a few
plain paragraphs with every term translated and one everyday comparison, then
follows the user's questions and makes it smaller when it does not land.
Nothing is changed, and any choices it surfaces are left for a separate walk.

## Prerequisites

None beyond the agent.
