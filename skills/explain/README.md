# explain

- Maintainer: the productivity plugin maintainers
- Submitted: 2026-10-02

Explains a problem or a topic before anything is changed: the problem as
observed with its evidence, the mechanism behind it, and, when a change is on the
table, two to four options with trade-offs and one recommendation. It then stops
and waits for the user's explicit go. With nothing pending it continues as a
dialogue.

## Prerequisites

None beyond the agent.
